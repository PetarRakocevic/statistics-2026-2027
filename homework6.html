Homework 6: Statistical independence and the chi-square test

Petar Rakočević, Cybersecurity MSc, Statistics 2026/27

1 Independence in probability and in statistics

1.1 Probability

Two events A and B are independent when P(A ∩ B) = P(A)·P(B). If P(B) > 0 this is the same as P(A | B) = P(A): learning that B happened does not change the probability of A. Two discrete random variables X and F, with values x1, …, xr and f1, …, fc, are independent when every pair of events {X = xi} and {F = fj} is independent:

pij = P(X = xi, F = fj) = P(X = xi)·P(F = fj) = pi··p·j for all i, j

Equivalently, the conditional distribution of F given X = xi is the same for every i, and therefore equal to the marginal distribution of F (and the same with the roles exchanged). Independence is a property of the joint distribution, i.e. of the model or the population, and it is symmetric. It is stronger than zero correlation: for X uniform on {−1, 0, 1} and Y = X², Cov(X, Y) = E[X³] = 0, yet Y is a function of X. For categorical variables such as attack type and outcome, correlation is not even defined, and independence is the only notion that applies.

1.2 Statistics

In statistics we observe n pairs (x, f) and summarise them in a contingency table of counts nij, with row totals ni·, column totals n·j and relative frequencies fij = nij/n. Descriptively, the two characters are statistically independent in the data when all conditional (row) distributions coincide with the marginal one, nij/ni· = n·j/n, which is the same as

nij = ni··n·j / n = Eij for all i, j

The numbers Eij are the theoretical (expected) frequencies under independence. Any departure from them is called association (or connection). In a real sample exact equality almost never holds, even when the variables are independent in the population, if only because Eij is usually not an integer. So the statistical question is inferential: are the observed departures larger than sampling error would produce? The tool is Pearson's chi-square statistic

χ² = Σi Σj (nij − Eij)² / Eij

which is 0 under perfect statistical independence and grows with the departure. Under the hypothesis H0: pij = pi·p·j, and for large n, χ² follows approximately a chi-square distribution with (r − 1)(c − 1) degrees of freedom. The count comes from rc − 1 free cell probabilities minus the (r − 1) + (c − 1) marginal probabilities estimated from the same data. The usual condition for the approximation is that all Eij ≥ 5. Since χ² grows with n for a fixed degree of association, the strength is measured separately by the mean square contingency Φ² = χ²/n and by Cramér's V = √(χ² / (n·min(r − 1, c − 1))), which lies between 0 (independence) and 1 (perfect association).

2 The dataset

The data continue the attacker-and-systems setting of Homeworks 3 and 4. Each record is one security event in an organisation's log. X is the attack vector (Phishing, Malware, Brute force, Web exploit) and F is the outcome (Blocked: stopped automatically; Detected: got through the first barrier but was found by monitoring; Compromise: led to a confirmed compromise). Each record also has the weekday of the event, used in chapter 8. The log contains n = 1500 events, generated with a seeded Mulberry32 generator (seed 2026) from the model below, so the true answer is known and the method can be checked against it. In the model the outcome depends on the vector and the weekday is drawn independently of everything.

The first records of the log, as the program reads them:

function crosstab(pairs,rows,cols){                 // pairs = [[x,f], ...]
  const O=rows.map(()=>cols.map(()=>0));
  for(const [a,b] of pairs) O[rows.indexOf(a)][cols.indexOf(b)]++;
  return O}
function analyze(O){
  const ri=O.map(r=>sum(r)), cj=O[0].map((_,j)=>sum(O.map(r=>r[j]))), n=sum(ri);
  const E=O.map((r,i)=>r.map((_,j)=>ri[i]*cj[j]/n));             // expected under independence
  const chi=sum(O.flat().map((o,k)=>(o-E.flat()[k])**2/E.flat()[k]));
  const df=(O.length-1)*(O[0].length-1), p=gammaQ(df/2,chi/2);    // upper tail of chi-square
  return {E,chi,df,p,V:Math.sqrt(chi/(n*Math.min(O.length-1,O[0].length-1)))}}

6 The chi-square statistic and the p-value

Contributions (nij − Eij)²/Eij of each cell, with row totals:

χ² = 100.91 with (4 − 1)(3 − 1) = 6 degrees of freedom. The critical value at α = 0.05 is χ²6; 0.95 = 12.59, so the observed statistic is eight times beyond it. The p-value is the upper tail P(χ²6 ≥ 100.91) = Q(3, 50.46), where Q is the regularized upper incomplete gamma function. Like the normal CDF of Homework 5 it has no elementary expression in general, so I compute it with its power series for x < a + 1 and a continued fraction otherwise. For an even number of degrees of freedom there is a closed form, which serves as a check: Q(3, x/2) = e−x/2(1 + x/2 + (x/2)²/2) = e−50.46·1324.4 = 1.62·10−19. The value agrees with SciPy's chi2_contingency to all printed digits. The likelihood-ratio statistic G² = 2Σ nij ln(nij/Eij) = 107.51 gives p = 6.8·10−21, the same conclusion. The smallest expected count is 28.12, far above 5, so the chi-square approximation is safe.

The strength is moderate: Φ² = 0.0673 and Cramér's V = 0.183. For comparison, the model that generated the data has population V = 0.203 (Φ² = 0.0827), so the sample estimate is in the right range.

7 Interpretation

The hypothesis of independence between attack vector and outcome is rejected (χ² = 100.91, df = 6, p = 1.6·10−19). If the two variables were independent, a table at least this far from the expected one would occur about once in 6·1018 logs of this size. The two variables are statistically dependent: knowing the vector changes the distribution of the outcome. The association is moderate (V = 0.18), not strong. Most of it comes from two vectors: the brute-force row contributes 60.99 of the 100.91 (60%), because these attacks are blocked far more often than average, and the web-exploit row contributes 23.19, because they end in compromise more often. Malware behaves like the average (row contribution 0.57). In practical terms, for a defender the outcome rate cannot be read from the overall 11.67% alone. The right reference is the conditional rate for the vector, from 4.6% to 19.1%.

8 A pair that is independent: weekday and outcome

The same log, with the weekday as the row variable:

Here χ² = 9.37 with 12 degrees of freedom, below the critical value 21.03, and p = 0.671: there is no evidence against independence. The compromise rate still varies between days, from 8.95% on Wednesday to 13.72% on Sunday, but differences of that size are what 1500 events produce by chance. No adjusted residual exceeds 1.78 in absolute value, and V = 0.056. The expected value of χ²12 under independence is 12, so 9.37 is an ordinary value. This is the correct answer, since the weekday was generated independently. It should be read as "not rejected", not as "proved independent". A small effect could exist and remain undetected with this n.

9 Checking the test by simulation

To check that the chi-square approximation and my p-value code behave as they should, I generated 5000 logs of 1500 events under H0, with cell probabilities equal to the product of the observed marginal frequencies, and computed χ² for each.

The simulated statistics follow the chi-square distribution: for the 4 × 3 table their mean is 6.01 and variance 11.98 (theory: df = 6 and 2·df = 12), for the 7 × 3 table 11.96 and 23.80 (theory 12 and 24). The share of simulated tables above the 5% critical value is 0.0488 and 0.0484, close to the nominal 0.05, so under independence the test makes about 5% false alarms, as it should. For the weekday table the Monte Carlo p-value (share of simulated χ² ≥ observed) is 0.669, against the analytic 0.671. For the vector-outcome table none of the 5000 simulated values came near the observed 100.91 (the largest was 28.88), so the Monte Carlo p-value is below 1/5001 ≈ 0.0002. The analytic value 1.6·10−19 is the only way to quantify how far beyond it lies.

10 Effect of the sample size

The same test on the first n events of the log:

With 30 or 50 events the dependence is not detected (p = 0.174 and 0.171). Also 10 and 8 of the 12 cells have expected counts below 5, so the chi-square approximation is not reliable there. From n = 100 the test rejects (p = 0.0028), and from n = 300 every expected count is at least 5. Cramér's V is large and noisy for small n (0.39 at n = 30) and settles around 0.18-0.21 from n = 500 on. χ², on the other hand, keeps growing: for a fixed association χ² ≈ n·Φ², so it grows linearly with n. This is why the p-value answers "is there any association?" and V answers "how strong is it?". With millions of log lines even a negligible association becomes "highly significant", so a p-value must never be read as a measure of strength.

11 Statistical association is not causality

A significant χ² says that the variables are not independent. It does not say why. Dependence between X and F can arise because X causes F, because F causes X, because a third variable Z affects both (confounding), or because of the way the data were selected. The chi-square test is symmetric in X and F and cannot tell these apart. In the event log, for example, the vector-outcome association could be produced partly by the targets: brute force typically hits login services protected by lockout rules, while web exploits hit exposed applications. The same vector against a different system might have a different outcome. The log also contains only events that were seen, so attacks that passed unnoticed are missing, which is a selection effect.

A well-known real example shows how far association and causation can diverge: the graduate admissions of the University of California, Berkeley, in 1973 (Bickel, Hammel and O'Connell, Science, 1975; the six largest departments, available in R as UCBAdmissions). Applicants: 4526.

Aggregated over departments, 44.52% of the men and 30.35% of the women were admitted. The 2 × 2 table gives χ² = 92.21 (df = 1, p = 7.8·10−22), clear dependence between gender and admission, with odds of admission 1.84 times higher for men. Department by department the picture changes: in four of the six departments (A, B, D, F) women were admitted at a higher rate, and the only significant difference is department A, in favour of women (82.41% against 62.06%, χ² = 17.25, p = 3.3·10−5). The Mantel-Haenszel common odds ratio, which compares men and women within departments, is 0.90.

The explanation is a confounder. Department is strongly associated with gender (χ² = 1068.4, df = 5, V = 0.49) and with admission (χ² = 778.9, df = 5, V = 0.41). 92.8% of the women applied to departments C to F, whose admission rates are between 6.4% and 35.1%, while only 48.5% of the men did; most men applied to A and B, which admitted 64.4% and 63.2%. The aggregate association is real as a statistical fact, but it is produced mostly by where people applied, not by how departments treated applicants of each gender. This is Simpson's paradox: an association can appear, disappear or reverse when a third variable is taken into account.

Establishing causation needs more than a contingency table. It needs a randomised experiment, in which the analyst assigns X (for example, a controlled phishing campaign in which each employee is randomly assigned to receive one of two message types), or an observational design that adjusts for the confounders that matter (stratification as above, or regression models), together with knowledge of the time order and of a plausible mechanism. The chi-square test answers a narrower question: is the distribution of F the same for every value of X?

13 Conclusions

The contingency table of 1500 security events shows that the outcome of an attack depends on its vector. The conditional outcome distributions differ markedly between vectors (compromise rate 4.6% to 19.1%), the observed counts depart from the expected counts under independence in a consistent pattern, and the chi-square test rejects independence decisively (χ² = 100.91, df = 6, p = 1.6·10−19), with a moderate strength (V = 0.18). For weekday and outcome, independent by construction, the test correctly finds nothing (χ² = 9.37, df = 12, p = 0.67). A simulation under H0 confirms that the statistic follows the chi-square distribution and that the test makes about 5% false rejections. The p-value depends on n while Cramér's V does not, so significance and strength must be reported separately. Finally, a rejected independence is a statement about association only: the Berkeley data show that an association can be produced entirely by a confounding variable, and causal claims need an experiment or an explicit adjustment for confounders.
